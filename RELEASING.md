# Release Stage Chat Codex

Follow the [Stage package release workflow](https://github.com/skyyware/stage/blob/main/docs/releases.md).
This repository owns `skyyware/stage-chat-codex` and its fixed CLI adapter.

Run `composer check`. A profile, model, or supported CLI change also needs
the documented default and Fast wire probes on the target binary and host,
with success, rejection, and concurrency checks. A documentation-only release
does not need another paid provider batch.

Install the exact public version in a fresh Composer consumer without
authentication or VCS overrides. Exercise `Codex::complete` through real
subprocess pipes with the local fake CLI, including explicit Fast selection.
Verify both this package's reference and the resolved Stage Chat reference.

The current release is 0.2.1. It preserves the 0.2.0 API and supported CLI
versions 0.159.2 and 0.159.3. Later releases must update the changelog, examples,
CLI compatibility, and verification limits before publication.
